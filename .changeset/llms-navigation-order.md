Generated `llms.txt` files follow the default language's sidebar, with pages in sidebar order: a **Documentation** section for the top-level navigation items, and one section for each navigation tab with items. Each page is listed under the tab that pages show for it, so agents see the same structure as readers. Discoverable pages that the sidebar does not list, such as translations, follow under **Other pages**.
