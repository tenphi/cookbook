## Начните со своего репозитория

Выполните эти команды в проекте, где уже есть `README.md` или каталог `docs/`:

```sh
npm create @tenphi/cookbook@latest docs-site -- --source . --yes
cd docs-site
npm run dev
```

Cookbook читает файлы на их текущем месте. Вы также можете [создать новый сайт](./getting-started.md), [описать именно те файлы, которые опубликованы в npm](./getting-started.md), или [добавить Cookbook в проект Astro](./getting-started.md).

## Этот сайт служит примером

Текущая страница находится в [docs/ru/index.md](https://github.com/tenphi/cookbook/blob/main/docs/ru/index.md). Небольшое [приложение Astro](https://github.com/tenphi/cookbook/tree/main/apps/reference) собирает сайт прямо из каталога `docs/` в репозитории. Навигация, поиск, элементы управления кодом, ссылки на редактирование и даты из Git доступны любому сайту Cookbook.

## Ваши материалы и оформление

### Храните исходные файлы там, где им место

Используйте Markdown-файлы и локальные ресурсы репозитория без копирования в дерево контента Astro. Cookbook также умеет читать спецификации OpenAPI и документацию npm-пакета, зафиксированного по версии и контрольной сумме. [Подробнее об источниках контента](../content-sources.md).

### Настройте сайт под свой продукт

Начните с фирменного цвета, затем настройте семантические палитры, шрифты, типографику и именованные части компонентов с помощью [Tasty](https://tasty.style) и [Glaze](https://glaze.tenphi.me). Частичные переопределения `theme.styles` объединяются со стандартными стилями Cookbook до извлечения CSS. В браузер отправляется статический CSS. [Подробнее о теме](../theme-and-components.md).

### Находите ошибки до публикации

Неработающие ссылки, отсутствующие ресурсы, дублирующиеся маршруты и неверная навигация вызывают ошибки с указанием исходного файла. Результат — предварительно созданный HTML с локальным поиском, готовый для любого статического хостинга. [Посмотрите порядок проверки](../quality-checks.md).
