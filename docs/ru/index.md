## Что вы получаете

- **Документация из существующих файлов.** Читайте Markdown, MDX и локальные ресурсы прямо из репозитория или собирайте сайт из npm-пакета, зафиксированного по версии и контрольной сумме. [Источники контента](../content-sources.md).
- **Генерация справочника API.** Превратите локальную спецификацию OpenAPI в обзор с поиском и отдельную страницу для каждой операции с параметрами, телами запросов, ответами и примерами. [Справочники OpenAPI](../content-sources.md#openapi-references).
- **Встроенный поиск.** Pagefind локально индексирует страницы и заголовки. Поиск открывается сочетанием клавиш, а его ресурсы загружаются по мере необходимости. [Поиск](../site-navigation.md#search).
- **Навигация для растущей документации.** Организуйте разделы с помощью вкладок и групп в боковой панели, добавьте оглавления и ссылки на предыдущую и следующую страницы, используйте выдвижное меню на мобильных устройствах. [Поиск и навигация](../site-navigation.md).
- **Компоненты для технических материалов.** Используйте вкладки, примечания, карточки, шаги, группы кода, подсветку с кнопками копирования и изолированные интерактивные примеры в MDX. [Компоненты для подготовки материалов](../authoring.mdx).
- **Тема в стиле вашего продукта.** Настройте фирменные цвета, семантические палитры, шрифты, типографику и части компонентов через [Tasty](https://tasty.style) и [Glaze](https://glaze.tenphi.me). Светлый, тёмный и высококонтрастный режимы получают статический CSS, созданный при сборке. [Тема и компоненты](../theme-and-components.md).
- **Языки и версии.** Публикуйте переводы и версии документации. Переключатели открывают соответствующую страницу, если она существует. [Языки и версии](../site-navigation.md#contents-languages-and-versions).
- **Проверки перед публикацией.** Находите неработающие ссылки, отсутствующие ресурсы, дублирующиеся маршруты и неверную навигацию с указанием исходного файла. Размещайте заранее созданный HTML на любом статическом хостинге. [Проверки качества](../quality-checks.md).
- **Страницы для распространения и чтения.** Публикуйте канонические URL, превью для социальных сетей, карты сайта, Markdown для скачивания и индекс `llms.txt` для агентов программирования. [Метаданные публикации](../publishing.md).

## Начните со своего репозитория

Выполните эти команды в проекте, где уже есть `README.md` или каталог `docs/`:

```sh
npm create @tenphi/cookbook@latest docs-site -- --source . --yes
cd docs-site
npm run dev
```

Cookbook читает файлы на их текущем месте. Вы также можете [создать новый сайт](./getting-started.md), [описать именно те файлы, которые опубликованы в npm](./getting-started.md), или [добавить Cookbook в проект Astro](./getting-started.md).

## Этот сайт служит примером

Текущая страница находится в [docs/ru/index.md](https://github.com/tenphi/cookbook/blob/main/docs/ru/index.md). Небольшое [приложение Astro](https://github.com/tenphi/cookbook/tree/main/apps/reference) собирает сайт прямо из каталога `docs/` в репозитории. Навигация, поиск, элементы управления кодом, ссылки на редактирование и даты из Git доступны любому сайту Cookbook.
